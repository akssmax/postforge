# Storyset illustrations

Illustrations in this folder are from [Storyset](https://storyset.com/) by Freepik.

## License

Storyset illustrations are free to use for personal and commercial projects with attribution.

When using these assets in published designs, include attribution such as:

> Illustrations by [Storyset](https://storyset.com/)

See [Storyset license](https://storyset.com/license) for full terms.

## How assets are bundled

SVGs are fetched from Storyset’s public API (`stories.freepiklabs.com`) via
`scripts/fetch-storyset-illustrations.mjs` and stored locally for instant use in Postforge’s
visuals library. Re-run the script to refresh the catalog.
